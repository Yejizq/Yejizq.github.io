STM32 HAL库 UART 中断接收详解

📅 2026-06-20 📂 STM32, 嵌入式 🏷️ STM32, UART, HAL库

概述

串口通信（UART）是嵌入式开发中最常用的通信方式之一。STM32 的 HAL 库提供了便捷的 UART 中断接收 API，但在实际使用中有不少坑需要注意。本文详细介绍 STM32 HAL 库中 UART 中断接收的配置与使用方法。

硬件准备

  • STM32F407VET6 开发板（或其他 STM32 系列）
  • USB 转 TTL 模块（CH340 / CP2102）
  • 杜邦线若干

CubeMX 配置

  1. 打开 STM32CubeMX，选择对应芯片型号
  2. 在 Pinout & Configuration 中启用 USART1，模式选择 Asynchronous
  3. 参数设置：波特率 115200，数据位 8，停止位 1，无校验
  4. 在 NVIC Settings 中勾选 USART1 全局中断
  5. 生成代码

代码实现

1. 初始化与启动接收

/* 全局变量 */
UART_HandleTypeDef huart1;
uint8_t rx_byte;  // 单字节接收缓冲

/* 在 main() 中初始化后启动中断接收 */
HAL_UART_Receive_IT(&huart1, &rx_byte, 1);

2. 中断回调函数

/**
 * @brief UART 接收完成回调函数
 * @param huart UART 句柄指针
 */
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart->Instance == USART1)
    {
        // 处理接收到的字节（存入环形缓冲区）
        ring_buffer_put(&uart_rx_buf, rx_byte);

        // 重新启动中断接收（关键步骤！）
        HAL_UART_Receive_IT(&huart1, &rx_byte, 1);
    }
}

3. 环形缓冲区（推荐）

#define RX_BUF_SIZE 256

typedef struct {
    uint8_t buffer[RX_BUF_SIZE];
    volatile uint16_t head;
    volatile uint16_t tail;
} RingBuffer;

RingBuffer uart_rx_buf = {0};

void ring_buffer_put(RingBuffer *rb, uint8_t data)
{
    uint16_t next = (rb->head + 1) % RX_BUF_SIZE;
    if (next != rb->tail)  // 非满
    {
        rb->buffer[rb->head] = data;
        rb->head = next;
    }
}

uint8_t ring_buffer_get(RingBuffer *rb, uint8_t *data)
{
    if (rb->head == rb->tail) return 0;  // 空
    *data = rb->buffer[rb->tail];
    rb->tail = (rb->tail + 1) % RX_BUF_SIZE;
    return 1;
}

常见问题与注意事项

1. 忘记重新启动中断接收

HAL 库的 HAL_UART_Receive_IT() 在接收到指定字节数后会自动关闭中断。必须在回调函数中重新调用它，否则后续数据将无法接收。

2. 使用 IDLE 中断接收不定长数据

上述单字节接收方式效率较低。对于不定长数据帧，推荐使用 IDLE 线路空闲中断 + DMA 方式：

// 在 main() 中
__HAL_UART_ENABLE_IT(&huart1, UART_IT_IDLE);  // 使能 IDLE 中断
HAL_UART_Receive_DMA(&huart1, dma_rx_buf, DMA_BUF_SIZE);

// 在 USART1_IRQHandler 中判断 IDLE 中断
if (__HAL_UART_GET_FLAG(&huart1, UART_FLAG_IDLE))
{
    __HAL_UART_CLEAR_IDLEFLAG(&huart1);
    // 处理接收到的完整帧数据
}

总结

使用 HAL 库进行 UART 中断接收的关键点：

  • ✅ 在回调中重新调用 HAL_UART_Receive_IT()
  • ✅ 使用环形缓冲区缓存数据
  • ✅ 推荐使用 IDLE 中断 + DMA 方式接收不定长数据
  • ✅ 注意中断优先级配置，避免串口中断被高优先级中断抢占导致丢数据
