ESP32 + DHT22 温湿度监测系统

📅 2026-06-18 📂 项目, ESP32 🏷️ ESP32, DHT22, MQTT

项目简介

本项目使用 ESP32 微控制器配合 DHT22 温湿度传感器，通过 MQTT 协议将环境数据上传至云平台，实现远程温湿度监测功能。适合智能家居、农业大棚等场景。

硬件清单

模块型号数量
主控ESP32-DevKitC1
传感器DHT22 (AM2302)1
显示屏(可选)0.96寸 OLED SSD13061

接线方式

ESP32    →   DHT22
3.3V     →   VCC
GND      →   GND
GPIO4    →   DATA (需接 4.7kΩ 上拉电阻到 3.3V)

核心代码

#include <WiFi.h>
#include <PubSubClient.h>
#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

const char* ssid = "your_wifi";
const char* password = "your_password";
const char* mqtt_server = "broker.emqx.io";

WiFiClient espClient;
PubSubClient client(espClient);

void setup() {
  Serial.begin(115200);
  dht.begin();
  WiFi.begin(ssid, password);
  client.setServer(mqtt_server, 1883);
}

void loop() {
  if (!client.connected()) reconnect();
  client.loop();

  float h = dht.readHumidity();
  float t = dht.readTemperature();

  if (!isnan(h) && !isnan(t)) {
    char msg[100];
    sprintf(msg, "{\"temp\":%.1f,\"humidity\":%.1f}", t, h);
    client.publish("home/sensors/dht22", msg);
    Serial.println(msg);
  }
  delay(5000);
}

总结

ESP32 + DHT22 是一个经典的物联网入门项目。通过 MQTT 协议可以轻松对接各类云平台（阿里云 IoT、EMQX、ThingsBoard 等），实现数据可视化与远程监控。
